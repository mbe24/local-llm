# Work-Order Briefing — local LLM

A tiny showcase: **structured task metadata → a natural prose dispatch briefing**,
generated by a **small language model running entirely in the browser** over
WebGPU. No server, no API keys — the model weights download once and are cached
locally.

The point of the demo is that the output is **provably generated, not string-
concatenated**. The UI edits a small flat config; from it, interdependent facts
are **derived in JavaScript** — the SLA clock (window − elapsed − travel), the
parts outlook (one trip vs. two), the clearance flag, the recurring-issue
history. The model never does arithmetic; it only weaves those resolved facts
into a spoken briefing. Swap the trade, tighten the clock, or drop a clearance,
and the whole briefing changes wholesale.

## Stack

- **Vite + Svelte 5** — single static page, tiny bundle.
- **[`@browser-ai/web-llm`](https://github.com/jakobhoeg/browser-ai)** `3.x` — a
  WebLLM provider for the **Vercel AI SDK** (`ai` v7). Inference runs in a **Web
  Worker** (`src/worker.js`) so the UI never blocks, with a real download-progress
  bar via `createSessionWithProgress`.
- **[`@mlc-ai/web-llm`](https://github.com/mlc-ai/web-llm)** — the underlying
  WebGPU engine.

Because every model backend the library supports (`web-llm`, `transformers-js`,
Chrome's built-in on-device model) is **client-side**, the whole thing hosts as a
static site with no backend — perfect for GitHub Pages.

## Run locally

Requires a WebGPU-enabled browser (Chrome, Edge, or Safari 18+).

```sh
npm install
npm run dev        # open the printed localhost URL
```

First generation downloads the selected model (Qwen3 0.6B ≈ 1.2 GB by default;
smaller options in the dropdown). Subsequent runs are instant from cache.

```sh
npm run build      # static site into dist/
npm run preview    # serve the built dist/ locally
```

## Layout

```text
src/
├── App.svelte              # orchestrator: config -> derived facts -> streamed briefing
├── worker.js               # WebLLM engine host (off the main thread)
├── app.css                 # single global stylesheet
├── lib/
│   ├── scenario.js         # trade presets, config defaults, JS fact-derivation, prompt
│   ├── llm.js              # AI SDK + WebLLM wrapper (worker, progress, streaming)
│   └── models.js           # the small-model dropdown list
└── components/
    ├── ConfigPanel.svelte  # the ~10-control work-order form
    ├── Briefing.svelte     # streamed output + progress bar
    └── RawJson.svelte      # collapsible "facts sent to the model" pane
```

## Customising

- **Change the domain:** the whole scenario lives in `TRADES` and `deriveFacts`
  in `src/lib/scenario.js`. Swap it for any structured task metadata.
- **Change the models:** edit `src/lib/models.js` (IDs from the
  [WebLLM prebuilt list](https://github.com/mlc-ai/web-llm/blob/main/src/config.ts)).
- **Tune the voice:** the system prompt is `SYSTEM_PROMPT` in `scenario.js`.
